# Phase 2: Data Science & Analytics Tasks

This folder contains the implementation of Phase 2 tasks for the DevelopersHub Internship.

## Included Tasks

### Task 1: Bank Marketing Term Deposit Prediction
* **Goal:** Predict whether a bank customer will subscribe to a term deposit based on marketing campaign data.
* **Tools:** Pandas, Scikit-learn, and Classification models to analyze customer behavior.

### Task 2: Customer Segmentation
* **Goal:** Group customers based on spending habits and annual income.
* **Algorithm:** K-Means Clustering to identify high-value customer segments.

### Task 5: Interactive Business Dashboard
* **Goal:** Create a real-time analytics tool for Global Superstore sales and profit data.
* **Tech Stack:** Streamlit, Plotly, Pandas.
* **Key Features:** Interactive filters for Region and Category, real-time KPI metrics, and profit trend visualizations.

## How to Run the Dashboard
1. Ensure you have the required libraries:
   `pip install streamlit pandas plotly xlrd`
2. Open your terminal in this folder.
3. Run the command:
   `streamlit run app.py`
